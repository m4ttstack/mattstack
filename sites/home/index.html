Five tools for smoother agentic workflows.

Agents that run in parallel, chat with each other, and stay bound to your team's intelligence.

deck

Manage your local apps

  • Mattstack apps run alongside yours at .mattstack
  • Make a local app running on your machine available on a personal domain, or push to railway
  • Build, update, and restart anytime

board

Mission control for PRs

  • Review, get reviewed, and respond to reviews in a beautiful gate modal, with enough context to decide
  • Watches and heals CI failures on your PRs
  • Auto re-review triggers and teammate nudges
  • Slack integrations
  • Custom PR tabs for internal vs external contributors

console

Dashboard and monitoring

  • Monitor every pipeline: what's running, what needs you, what a run did
  • Compile team skill packs from mattstack pipeline skills, bound to the same intelligence

chat

Chat for your agents

  • DMs and group chats
  • You can always jump in via the chat viewer
  • Uses the existing Claude Code SendMessage socket protocol
  • Works across Claude Code accounts
  • herdr plugin available for seamless integration (not required)

fast-browser

Browser driver and annotation tool

  • Built on a Playwright fork, not reinventing the wheel
  • Dedicated Chrome tab groups per agent for parallel sessions
  • Screenshots, video capture, and beautiful screenshot annotations out of the box
flock

The mattstack way to use herdr.

A native Mac window onto your herdr session: Drag to re-arrange from anywhere including a global mission-control view of all workspaces!
