# Slack support chat

A support chat lets one of your Claude panes help a teammate over a Slack direct message. The teammate writes in Slack. The pane answers there, and you can watch and steer from the chat viewer. The pane only reads and explains: it never edits files, commits or pushes for a teammate.

Every pane reply starts with `[Maude 🤖]: `, so the teammate can tell it is the bot and not you. Maude is the default name. Change the name and emoji in the `agent.persona` setting, for example `{ "name": "Ada", "emoji": "🦊" }`. Change the words a teammate uses to ask for the bot again in the `chat.slackSupport.trigger` setting, for example `"!!ada"`. Without a trigger, it is the name after an `@`. A change applies to the next message.

## Set up

Do this once for your Slack app and once on each Mac that opens chats.

1. The app's owner adds four user scopes on the app's OAuth page: `im:history`, `im:read`, `im:write` and `users:read`. A workspace admin may need to approve them.
2. Open mattstack's **Settings > Accounts** and press **Connect** on the **Slack support chat** row, or run:

   ```bash
   rt setup slack connect --support-chat
   ```

   This lets your Slack token read your direct messages, so only do it if you run support chats. Nobody else needs it, and nothing in setup asks for it. If the app doesn't list the scopes yet, your current token stays as it is. Slack may grant less than you asked for, and the row then names what the app's owner needs to add. Or Slack may refuse the request, and the connect fails and names those scopes.

3. Update the mattstack Claude plugin, which adds the `/slack-support` command:

   ```bash
   claude plugin update mattstack@mattstack
   ```

   Then run `/reload-plugins` in your Claude Code session.

4. Install the herdr chat plugin, or reinstall it if you already have it, so the new controls show up:

   ```bash
   herdr plugin install m4ttstack/mattstack/plugins/herdr-chat
   ```

5. To file tickets in Linear, store a Linear API key scoped to your SUPPORT team:

   ```bash
   rt secrets set rt linearSupportApiKey
   ```

You don't need to sign the pane in to rt chat first: `/slack-support` signs it in. See the [chat guide](/rt/guides/chat).

## Open a chat

In the pane, type:

```text
/slack-support <person> <problem>
```

Put a full name in quotes:

```text
/slack-support "Alex Example" the printer won't print
```

The pane writes a short brief, then sends the teammate a first message.

You approve every chat. Any Claude pane can ask for one with the `chat_slack_request` tool. The pane shows you the question as a form, and the request also waits on the console's **Slack gates** page. The chat opens only when you approve it, and a background agent then holds the DM and tells the asking pane how it goes. A teammate who sends you a message starting with the bot's trigger is offered as a new chat for you to approve.

You can also use the **On** control in the pane's Slack support action, which types the command for you. **Off** closes the chat. That action isn't in the herdr chat launcher, so [bind it to a key](/skills/herdr-chat#bind-keys).

## During a chat

- The teammate's replies reach the pane within a few seconds.
- A message you type in Slack is seen by both the teammate and the pane.
- A message you send from the chat viewer reaches only the pane. The teammate never sees it.
- A chat starts when you turn it on. The pane never sees anything earlier in the DM, and a thread reply under a message from before the chat is never seen.
- The pane cannot read attachments. It asks the teammate to paste the text.

## How a chat ends

- The pane closes it once the teammate confirms the problem is sorted.
- After 30 quiet minutes the pane checks in. After 60 quiet minutes the chat closes.
- You can close it with **Off**.
- Ending the pane's Claude session closes it at once: exiting, closing the pane, `/clear`, `/resume`, or signing the pane out of chat. There is no farewell. rt tells the teammate you will follow up, and sends you a desk notification.

On close the pane sends a short farewell, and rt adds a fixed line saying anything further goes to you. The pane then sends you a message with the outcome and any tickets it filed. After that, what the teammate sends is an ordinary DM to you.

## Pick a chat back up

A closed chat keeps its agent for 60 minutes. In that time, a teammate message that starts with the bot's trigger asks you whether to resume. You can resume any closed chat yourself at any time, from **Resume** in the chat viewer's closed thread, and a pane can ask with the `chat_slack_resume` tool, which waits for your approval like a new request. A resumed chat reuses the agent if it is still running, or starts a fresh one that sees the earlier tickets.

## Tickets

When a teammate reports a bug or asks for a feature, the pane files it in your Linear SUPPORT team with the `chat_slack_ticket` tool. Each ticket has the problem, the idea or fix, acceptance points and where it came from. The pane tells the teammate it was written up, but never sends the ticket's id or link to Slack. The asking pane hears about each ticket.
