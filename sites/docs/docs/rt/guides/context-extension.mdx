# Editor extensions

mattstack.app ships two editor extensions: `rt-context` and `skill-blocks`.

Setup installs both into every VS Code-family editor it finds: VS Code, Cursor, Antigravity, Windsurf, VSCodium and the like. It does this whether you install through mattstack.app's setup window or `rt --post-install`. When the app updates, setup updates both extensions in the editors it installed them into, so most people never need to think about them.

## RT Context

The `rt-context` extension shows your current worktree, branch, and linked Linear ticket in the status bar, so you always know which context you're in without running a command.

### Status bar

```
📁 main-worktree  │  🔖 ACME-1287: Add damage photo uploads
```

Clicking the item opens a short menu. It opens the linked Linear ticket or the MR or PR, or shows the worktree in Finder. Three more items sit beside it:

- **Worktrees** lists the repo's worktrees in the same order and groups as `rt cd`, hiding the spare, golden and gitq trees it hides. A row with no ticket title shows its MR or PR title instead.
- **Agents** lists this worktree's Claude agents: live Claude panes in the worktree, finished `rt agent` sessions recorded for it, and sessions from work and review runs on its branch. The count beside it is the live ones. Picking a row opens an integrated terminal attached to that session, the way `rt pane attach` does in a terminal.
- The branch item switches branches.

Ticket titles and links come from the rt daemon, which reads your Linear key and GitLab token from rt's secrets. Set them with `rt secrets set rt linearApiKey` and `rt secrets set rt gitlabToken`. A repo whose tickets live in a second Linear workspace can name a different secret with the `rt.linearKey` setting, such as `linearApiKey.mattstack`.

## Skill Blocks

The `skill-blocks` extension helps you write skills. It gives `*.block.md` files, `skills.jsonc` manifests and the markdown they fill errors as you type, hover, go to definition, completion, references, rename and quick fixes. It runs `rt skills lsp`, so it needs `rt` on your PATH or at `~/.local/bin/rt`.

## Reinstalling or adding editors

```bash
rt settings extension
```

This opens a fuzzy picker to select which editors (Cursor, VS Code, Antigravity, and the like) to install into. It installs both extensions. Use it to reinstall after an editor update, or to add the extensions to an editor you installed after setup.

See the full command reference: [`rt settings extension`](/rt/reference/settings/extension).
