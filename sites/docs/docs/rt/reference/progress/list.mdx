# rt progress list

`rt › progress › list`

Plans recorded on this machine and whether each finished

## Usage

```bash
rt progress list [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `--tree` | text |  | Only plans recorded for this worktree root |
| `--plan` | text |  | Only this plan, by path or file name |
| `--refresh` | boolean | `false` | Save the tree's ledgers first; needs --tree |
| [`--json`](/rt/guides/common-flags) | boolean | `false` | Accepted; output is always JSON |
