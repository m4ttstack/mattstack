# rt pane attach

`rt › pane › attach`

Pick one of your Claude agents and jump into its terminal

## Usage

```bash
rt pane attach [<pane>] [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `<pane>` | text |  | The herdr pane to attach to; leave it out to pick one |
| `--takeover` | boolean | `false` | Take the pane over from any other attached terminal |
