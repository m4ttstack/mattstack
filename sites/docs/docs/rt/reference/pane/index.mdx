# rt pane

`rt › pane`

herdr panes as rt sees them: list with chat presence, peek, spawn claude, cswap accounts, directory suggestions

## Usage

```bash
rt pane
```

## Subcommands

| Command | Description |
| --- | --- |
| [`list`](/rt/reference/pane/list) | Claude panes with their chat handle, status and rooms joined in (needs herdr) |
| [`peek`](/rt/reference/pane/peek) | The last lines of a pane's visible screen |
| [`spawn`](/rt/reference/pane/spawn) | Open a herdr tab in a directory and start claude in it, optionally under a cswap account |
| [`send`](/rt/reference/pane/send) | Inject text into a pane as if typed and submitted; self is this pane (--text - reads stdin) |
| [`focus`](/rt/reference/pane/focus) | Bring a herdr pane to the front (via the tray: workspace + tab focus and terminal window raise) |
| [`accounts`](/rt/reference/pane/accounts) | cswap accounts with rate-limit headroom, for spawn --account |
| [`directories`](/rt/reference/pane/directories) | Repos and worktrees rt knows, as suggestions for spawn --cwd |
