# rt dev update

`rt › dev › update`

Update your tools and dev app

## Usage

```bash
rt dev update [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `--release` | boolean | `false` | Swap a dev app built on this Mac for the release's |
| `--auto` | boolean | `false` | Update the clone and the dev app together only when the clone is clean and on main, as the daemon does each hour |
| [`--json`](/rt/guides/common-flags) | boolean | `false` | Machine-readable result |
