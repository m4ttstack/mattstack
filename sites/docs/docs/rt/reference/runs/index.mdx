# rt runs

`rt › runs`

Pipeline run state: list, show, and the pipeline's write verbs

## Usage

```bash
rt runs [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| [`--repo`](/rt/guides/common-flags) | text |  | Scope to one registry repo |
| `--include-tests` | boolean | `false` | Also list runs a validation harness started |

## Subcommands

| Command | Description |
| --- | --- |
| [`show`](/rt/reference/runs/show) | One run: stages, fields, decisions |
| [`abandon`](/rt/reference/runs/abandon) | Mark a wedged run abandoned (the run died with its session and the DB still says running) |
| [`find`](/rt/reference/runs/find) | Runs whose claude-session field matches; read-side, no daemon |
| [`run-start`](/rt/reference/runs/run-start) | Pipeline: open a run DB and print its runId and runDb |
| [`run-status`](/rt/reference/runs/run-status) | Pipeline: close the run (reads RT_RUN_DB) |
| [`stage-start`](/rt/reference/runs/stage-start) | Pipeline: start a stage attempt (reads RT_RUN_DB) |
| [`stage-done`](/rt/reference/runs/stage-done) | Pipeline: finish the latest attempt of a stage (reads RT_RUN_DB) |
| [`stage-fail`](/rt/reference/runs/stage-fail) | Pipeline: fail the latest attempt of a stage (reads RT_RUN_DB) |
| [`stage-redirect`](/rt/reference/runs/stage-redirect) | Pipeline: leave the latest running attempt of a stage as redirected (reads RT_RUN_DB) |
| [`field`](/rt/reference/runs/field) | Pipeline: field set KEY VALUE --stage NAME [--if-sha256 HEX] \| field get KEY (reads RT_RUN_DB) |
| [`decision`](/rt/reference/runs/decision) | Pipeline: decision record --contract C --scope S --selection JSON --decided-by W (reads RT_RUN_DB) |
| [`snapshot`](/rt/reference/runs/snapshot) | Pipeline: the full run document as JSON (reads RT_RUN_DB) |
