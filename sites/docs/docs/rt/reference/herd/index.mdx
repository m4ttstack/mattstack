# rt herd

`rt › herd`

Run a herd: registry, worker questions as gates, chat room, lifecycle

## Usage

```bash
rt herd
```

## Subcommands

| Command | Description |
| --- | --- |
| [`start`](/rt/reference/herd/start) | Start a herd: registry row, chat room, herdr workspace, gate subscription |
| [`spawn`](/rt/reference/herd/spawn) | Spawn a worker job: worktree, herdr pane, Claude agent |
| [`ask`](/rt/reference/herd/ask) | Worker: opens a gate; end the turn, the answer arrives as a nudge |
| [`milestone`](/rt/reference/herd/milestone) | Worker: posts the artifact and opens a milestone gate; end the turn |
| [`answer`](/rt/reference/herd/answer) | Worker: read the answer to a gate this job is holding at |
| [`report`](/rt/reference/herd/report) | Worker: post the final report into the herd room and mark the job done |
| [`gates`](/rt/reference/herd/gates) | Open gates across a herd's workers |
| [`status`](/rt/reference/herd/status) | One herd: jobs, panes, gates, subscription, unread |
| [`list`](/rt/reference/herd/list) | Herds on this machine: id, status, room, job count |
| [`resume`](/rt/reference/herd/resume) | Re-point a herd's gate subscription and chat handle at this session |
| [`close`](/rt/reference/herd/close) | Close a worker job: retires the row and closes its pane |
| [`follow-up`](/rt/reference/herd/follow-up) | Reopen a done job for a follow-up round: active again until its next report |
| [`attend`](/rt/reference/herd/attend) | Attach a worker's pane in a tab of your own workspace |
| [`wrap-up`](/rt/reference/herd/wrap-up) | Wind a herd down: panes, worktrees, job dirs, room |
| [`stop`](/rt/reference/herd/stop) | Stop the hidden herdr session that hidden herds run in |
| [`brief`](/rt/reference/herd/brief) | Assemble a job brief from the shepherd skill's template + strategy body (paths passed explicitly) |
