# rt tools restart

`rt › tools › restart`

Restart herdr's servers that run an older herdr (ends their panes)

## Usage

```bash
rt tools restart <tool> [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `<tool>` | text |  | Tool name (herdr) |
| `--server` | text |  | Stop only this server (repeatable), and only while it runs an older herdr |
| [`--json`](/rt/guides/common-flags) | boolean | `false` | Machine-readable result |
