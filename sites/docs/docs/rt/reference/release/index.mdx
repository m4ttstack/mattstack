# rt release

`rt › release`

Release-cycle verbs for the rt repo itself

## Usage

```bash
rt release
```

## Subcommands

| Command | Description |
| --- | --- |
| [`preflight`](/rt/reference/release/preflight) | Read-only report of every vendored layer's pin freshness, git/tag state, and the gate the pending diff implies |
| [`verify`](/rt/reference/release/verify) | Read-only confirmation that a tagged release actually published: the workflow run, notes, assets, draft state, and releases/latest |
| [`update-machine`](/rt/reference/release/update-machine) | Bring this machine's prod app, dev bundle, daemon, and served suite up to a released tag |
| [`apps`](/rt/reference/release/apps) | Ship a quick patch release of the web apps that changed |
