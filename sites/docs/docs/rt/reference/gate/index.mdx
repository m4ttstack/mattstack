# rt gate

`rt › gate`

Human-decision gates: pause a subject until answered, parked, or closed

## Usage

```bash
rt gate
```

## Subcommands

| Command | Description |
| --- | --- |
| [`open`](/rt/reference/gate/open) | Open a human-decision gate on a subject |
| [`ask`](/rt/reference/gate/ask) | Open a gate with the daemon-side ceremony (subject resolution, presentation, nudge) |
| [`answer`](/rt/reference/gate/answer) | Answer an open gate |
| [`wait`](/rt/reference/gate/wait) | Block until a gate is answered or closed (default: wait forever) |
| [`list`](/rt/reference/gate/list) | List gates |
| [`park`](/rt/reference/gate/park) | Park an open gate (paused, not closed) |
| [`close`](/rt/reference/gate/close) | Close a gate without an answer |
| [`subscribe`](/rt/reference/gate/subscribe) | Subscribe a session to gates opened under a subject prefix |
| [`unsubscribe`](/rt/reference/gate/unsubscribe) | Remove a gate subscription |
| [`subscriptions`](/rt/reference/gate/subscriptions) | List gate subscriptions |
