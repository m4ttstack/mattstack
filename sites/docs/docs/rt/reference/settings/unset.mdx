# rt settings unset

`rt › settings › unset`

Remove a setting from one layer

## Usage

```bash
rt settings unset <key> [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `<key>` | text |  | Namespaced settings key to remove |
| `--scope` | select |  | Which store to remove it from |
| [`--repo`](/rt/guides/common-flags) | text |  | Registered repo (name, path, or identity); required for repo-scoped keys |
| `--team` | text |  | A team's name, for --scope team; your own team when left out |
