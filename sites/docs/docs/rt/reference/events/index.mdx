# rt events

`rt › events`

Optional event bus for panes and skills

## Usage

```bash
rt events
```

## Subcommands

| Command | Description |
| --- | --- |
| [`emit`](/rt/reference/events/emit) | Publish an event to a topic |
| [`wait`](/rt/reference/events/wait) | Block until a matching event lands (long-poll; exit 124 on timeout) |
| [`tail`](/rt/reference/events/tail) | Stream matching events as NDJSON until interrupted |
| [`list`](/rt/reference/events/list) | Read matching events from the journal (non-blocking) |
