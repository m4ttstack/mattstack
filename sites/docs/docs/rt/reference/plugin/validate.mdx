# rt plugin validate

`rt › plugin › validate`

Deep-validate installed plugins

## Usage

```bash
rt plugin validate <plugin> [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `<plugin>` | text |  | Validate only this plugin by directory name; omit to validate all installed plugins |
| [`--json`](/rt/guides/common-flags) | boolean | `false` | Print the result as one JSON object |
