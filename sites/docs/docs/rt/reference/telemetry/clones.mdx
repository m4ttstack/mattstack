# rt telemetry clones

`rt › telemetry › clones`

See whose org copy is stuck, dirty or behind, and what happened to it

## Usage

```bash
rt telemetry clones [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `--user` | text |  | Only this person's Macs (their forge username) |
| [`--json`](/rt/guides/common-flags) | boolean | `false` | Machine-readable result |
