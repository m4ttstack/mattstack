# rt skills history-classify

`rt › skills › history-classify`

Tell which of an org clone's commits changed only version numbers

```bash

```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `--repo-dir` | text |  | The org clone whose history to read |
