# rt skills lsp

`rt › skills › lsp`

Check skill block files and their bindings as you edit them, for your editor

## Usage

```bash
rt skills lsp [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `--root` | text |  | Folder to look in (repeatable); omit to use the editor's workspace folders |
| `--stdio` | boolean | `false` | Accepted for editors that pass it; the server always talks over stdin and stdout |
