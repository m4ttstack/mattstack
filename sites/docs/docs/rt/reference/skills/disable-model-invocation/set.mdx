# rt skills disable-model-invocation set

`rt › skills › disable-model-invocation › set`

Disable model invocation on pack skills, or turn it back on

## Usage

```bash
rt skills disable-model-invocation set <skills> [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `<skills>` | text |  | One or more skill names in the pack; omit to pick |
| `--pack` | text |  | Pack name; omit to pick from the discovered packs |
| `--on` | boolean | `false` | Disable model invocation on the named skills |
| `--off` | boolean | `false` | Let Claude invoke the named skills again |
| [`--json`](/rt/guides/common-flags) | boolean | `false` | Machine-readable result |
