# rt worktree

`rt › worktree`

Create, list and clean up worktrees

## Usage

```bash
rt worktree
```

## Subcommands

| Command | Description |
| --- | --- |
| [`provision`](/rt/reference/worktree/provision) | Get a worktree for a ticket or branch |
| [`hook`](/rt/reference/worktree/hook) | Set up Claude Code to use rt worktrees |
| [`create`](/rt/reference/worktree/create) | Create a new worktree |
| [`dispose`](/rt/reference/worktree/dispose) | Clean up a worktree |
| [`restore`](/rt/reference/worktree/restore) | Bring back a cleaned-up worktree |
| [`ready-approve`](/rt/reference/worktree/ready-approve) | Approve a repo's setup script before it runs |
| [`list`](/rt/reference/worktree/list) | List worktrees |
| [`triage`](/rt/reference/worktree/triage) | See why worktrees are stuck and what's safe to do |
| [`freshen`](/rt/reference/worktree/freshen) | Bring spare worktrees up to date with main |
| [`enable`](/rt/reference/worktree/enable) | Turn worktrees on for this Mac |
| [`await-ready`](/rt/reference/worktree/await-ready) | Wait for a new worktree to finish setting up |
| [`adopt`](/rt/reference/worktree/adopt) | Bring a repo's existing worktrees under rt |
| [`each`](/rt/reference/worktree/each) | Run a command in every worktree |
