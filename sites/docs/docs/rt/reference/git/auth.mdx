# rt git auth

`rt › git › auth`

Let git sign in with rt's forge token

## Usage

```bash
rt git auth [<path>] [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `<path>` | text |  | The clone to set up |
| `--https` | boolean | `false` | Switch an SSH clone to HTTPS too |
| `--check` | boolean | `false` | Show which clones use rt's token |
| `--yes` | boolean | `false` | Skip the confirm |
| [`--json`](/rt/guides/common-flags) | boolean | `false` | Print JSON |
