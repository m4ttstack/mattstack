# rt team publish

`rt › team › publish`

Push your org changes, and any new pack not shared yet, to the org repo

## Usage

```bash
rt team publish [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `--team` | text |  | Which org clone; your only one when left out |
| `--remote` | text |  | Set (or change) the remote before pushing |
| [`--json`](/rt/guides/common-flags) | boolean | `false` | Machine-readable result |
