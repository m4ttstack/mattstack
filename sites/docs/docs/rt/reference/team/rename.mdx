# rt team rename

`rt › team › rename`

Rename your org

## Usage

```bash
rt team rename <name> [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `<name>` | text |  | The org's new name: lowercase letters, digits and dashes |
| `--team` | text |  | Which org clone; your only one when left out |
| [`--json`](/rt/guides/common-flags) | boolean | `false` | Machine-readable result |
