# rt team admin-secrets

`rt › team › admin-secrets`

Share the switchboard admin token with your org's owners and admins, and keep it locked to them

## Usage

```bash
rt team admin-secrets [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `--team` | text |  | Which org clone; your only one when left out |
| `--replace-token` | boolean | `false` | Put this Mac's token in even when the org already shares a different one |
| [`--json`](/rt/guides/common-flags) | boolean | `false` | Machine-readable result |
