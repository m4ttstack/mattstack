# rt team branch use

`rt › team › branch › use`

Switch your copy of the org to a branch, for trying a change before everyone gets it

## Usage

```bash
rt team branch use <branch> [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `<branch>` | text |  | The branch to switch to; created from the org's data branch when it doesn't exist |
| `--team` | text |  | Which org clone; your only one when left out |
| [`--json`](/rt/guides/common-flags) | boolean | `false` | Machine-readable result |
