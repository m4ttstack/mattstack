# rt team members set

`rt › team › members › set`

Change which teams someone is on

## Usage

```bash
rt team members set <username> [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `<username>` | text |  | The member's forge username |
| `--teams` | text |  | Their teams, comma separated; the first is the one they start on |
| `--team` | text |  | Which org clone; your only one when left out |
| [`--json`](/rt/guides/common-flags) | boolean | `false` | Machine-readable result |
