# rt team support on

`rt › team › support › on`

Choose whose Mac answers, and turn support on

## Usage

```bash
rt team support on [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `--host` | text |  | Whose Mac answers; the one already set when left out |
| `--team` | text |  | Which org clone; your only one when left out |
| [`--json`](/rt/guides/common-flags) | boolean | `false` | Machine-readable result |
