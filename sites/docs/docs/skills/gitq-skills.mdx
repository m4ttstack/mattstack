# gitq skills

gitq ships four Claude skills of its own: `gitq:sync`, `gitq:publish`, `gitq:absorb` and `gitq:restructure`. Each owns one action the gitq board can launch. In each, gitq does the git mechanics deterministically. The skill supplies the judgment gitq has no opinion about, such as merging a conflict's two sides for real or writing MR descriptions from the actual diff.

They are separate from the `mattstack` plugin on this tab. See [Drive gitq with agents](/gitq/guides/agent-skills) for what each skill owns and how to install it.
