# Hand back with the Minor findings listed

Ship as is: hand back to the calling flow with each unfixed Minor
finding recorded as left open (an `Open:` bullet in `review`), plus every finding left open or not reproduced; an
unfixed Critical or Important counts as left open. Judgment calls and
owed evidence go with them under those names, so the owed evidence still
reaches ship. The draft's
`Unanswered rules:` line, when it has one, goes with them.
