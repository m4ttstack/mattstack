# Did the fix round change code?

Yes when any change the round kept is code. No when the round kept no
change at all, or when every kept change is comment text: it closes
without a re-review and without a `rereview-rounds` charge. A round whose
findings were all not reproduced, left open with their attempts undone,
judgment calls or owed evidence kept no change. Comment text and code are
sorted as below.
