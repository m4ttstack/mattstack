# GitHub reply result?

The post posted, or the tool returned an error. On an error the thread is
held this pass: it neither resolves nor posts again, its id joins the held
ids of the closing re-record, built as Hold the picked fix rows and report
the failure verbatim describes (`gateId`, or `decidedBy` and rebuilt
`answers`), and its error is quoted whole and unedited in the held report.
