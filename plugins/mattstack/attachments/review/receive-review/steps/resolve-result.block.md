# GitHub resolve result?

The thread resolved, or the tool returned an error. On an error the thread
is held this pass: its id joins the held ids of the closing re-record, built as Hold the
picked fix rows and report the failure verbatim describes (`gateId`, or
`decidedBy` and rebuilt `answers`), and its error is quoted whole and
unedited in the held report.
