# Off-script gate: the GitHub threads did not read

Quote the `mr_threads` error, or the threads whose notes did not come back,
as the `context`, and say nothing was posted. Propose: the human fixes
the cause, or posts and resolves every due thread by hand, each spelled out
in the move, then this verb reads again and acts on what is left.
A PR-level row's reply posted by hand ends with its marker line
(Post the reply on GitHub), spelled out in the move, or the next read
posts it again.
Never post without the read.
