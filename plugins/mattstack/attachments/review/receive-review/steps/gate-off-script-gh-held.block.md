# Off-script gate: GitHub threads held this pass

One gate for every thread held this pass. Quote each as the `context`: its
id, what was due on it, and the git reads' output or the tool's error,
whole and unedited. Propose: the human fixes the cause (the branch, the
push, the forge) or posts and resolves those threads by hand, then this
verb reads the threads again and acts on the held ones alone.
A PR-level row's reply posted by hand ends with its marker line
(Post the reply on GitHub), spelled out in the move, or the next read
posts it again.
Never switch branches, rebase or push to make a mismatch match.
