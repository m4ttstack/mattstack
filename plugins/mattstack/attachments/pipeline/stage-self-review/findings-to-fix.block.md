# Findings to fix?

Yes when the review raised a finding the stage fixes (Fix each finding
test-first, commit). No when it raised none, or only judgment calls and
evidence only the pushed branch can show, or, on a review after a fix
round, only Minor findings. Those Minors are not fixed: each goes into
`review` as an `Open:` bullet, so a nit left after the fixes were reviewed
buys no further round.
