# UI work is not done until it is seen

A change to a UI is not done until it has been rendered and looked at: a web
UI in Fast Browser, a native app UI through the repo's own UI harness or a
screenshot of the running app.

- Screenshot both colour schemes.
- Say plainly what looks wrong, rather than declaring success.

Tests, contrast maths and a clean review do not catch "this reads wrong".
Tell your subagents the same.
