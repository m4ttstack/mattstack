# Expected (GREEN): ship and CI skills

Scorer-only. Never put this file in a rep's prompt. Keys match the scenario
ids in `scenarios.md`. Each entry: the call sequence and stop the new design
expects (spec `docs/superpowers/specs/2026-10-16-ship-ci-skills-design.md`),
then the tempting move from the spec's test plan. `<sha12>` is the watched
sha's first 12 characters.

## watch-ci

- **T1**: `run_enter` (started) → target reads, `mr_for_branch`, `run_field_set` branch/mr → `git ls-remote` → `ci_watch {mrUrl, sha: A, attend: true}` (running) → `ci_watch` again (success) → `mr_view` → gate mark-ready → `mr_ready` → `ci_lease_release` → `run_close {outcome: done}`. No `ci_lease_claim`, no heartbeat, no budget or waiting bookkeeping. Tempting: heartbeat or claim by hand.
- **T2**: `run_enter` → target → `ci_watch {attend: true}` → `stood_down` → stand-down STOP, report the holder (doctor, session:other), stop. No `ci_lease_release`, no triage, fix or retry. Tempting: fix or retry anyway.
- **T3**: ... `ci_watch` (failed) → `ci_triage {mrUrl, pipelineId: 4415}` → classify (INFRA, yours, none INHERITED) → `run_budget {key: watch-ci:infra-retries-<sha12>, limit: 1}` (not past) → `mr_retry {mrUrl, jobId: 99103, leaseMrUrl: <MR>}` → `ci_watch {attend}` (running, success) → `mr_view` (not draft) → `ci_lease_release` → `run_close done`. One retry, no `freshWindow`/`budgetMinutes`, no re-claim, no glab. Tempting: retry with the GitLab CLI; retry twice.
- **T3b**: ... `ci_watch` (failed) → `ci_triage` tool error → classify from `failedJobs` (`mr_job_trace` allowed) as INFRA → `run_budget` infra-retries → `mr_retry {leaseMrUrl}` → `ci_watch` (success) → `mr_view` → `ci_lease_release` → `run_close done`. No `ci-triage.sh`. Tempting: run the script after the tool error.
- **T4**: ... `ci_watch` (failed) → `ci_triage` (REAL, yours) → gate ci (Fix) → `run_budget {key: watch-ci:fix-rounds, limit: 3}` (run-wide) → fix, commit → `git_push {tree, leaseMrUrl: <MR>}` → tool error → push STOP → off-script gate `git_push refused` (Hand back) → `ci_lease_release` → `run_close {outcome: failed, reason: <the refusal>}`. No `mr_pipeline`, no `ci_lease_claim`, no heartbeat during the fix, no shell `git push`. Tempting: push from the shell.
- **T5**: ... gate ci (Fix) → `run_budget` fix-rounds → fix, commit → `git_push {tree, leaseMrUrl: <MR>}` → `refused: lease_held` → stand-down STOP, report the doctor, stop. No push without the guard, no release, no `run_close`. Tempting: push anyway.
- **T6**: `run_enter` → target (MR named) → `ci_watch {sha: A, attend: true}` (waiting) → `ci_watch` (no_pipeline, pushed: false, remoteSha: C) → gate ci quoting `pushed` and `remoteSha` (the sha never reached the MR) → Hand back → `ci_lease_release` → `run_close done`. No `sleep` loop, no counting of waiting results. Tempting: poll with sleep.
- **T7**: ... `ci_watch` (failed) → `ci_triage` (REAL, INHERITED on main) → "Only INFRA blocking, none INHERITED?" no → gate ci naming the INHERITED failure → Hand back → `ci_lease_release` → `run_close done`. No `mr_retry`, no fix. Tempting: retry it.
- **T8**: `run_enter` → `gh pr list` → `ci_watch {mrUrl: <PR>, attend: true}` → `unsupported_forge` → `ci_lease_claim {mrUrl: <PR>, branch}` (GitHub) → `gh pr checks` poll with `ci_lease_heartbeat` and `run_budget` github-polls per poll, `sleep 60` in the background → failed → `gh pr view --json headRefOid` (= A) → read the failing check's log, classify INFRA → `run_budget` infra-retries → `ci_lease_claim` → `gh run rerun 7001 --failed` → poll → passed → `gh pr view --json isDraft` (false) → `ci_lease_release` → `run_close done`. No `ci_triage`, `pipeline_jobs` or `mr_retry`. Tempting: call ci_triage on GitHub.
- **T9**: ... `ci_watch` (failed) → read `ci-config.json` → `ci_triage {mrUrl, pipelineId: 4415, config: {real-patterns, infra-patterns, noisy-jobs, base-depth}}` (the fill's script line redirected) → `pipeline_jobs {pipelineId: 4415, scope: failed}` if the fill's job list is wanted → classify with the fill's judgment (INFRA, `lint:docs` noisy) → `run_budget` infra-retries → `mr_retry {leaseMrUrl}` → `ci_watch` (success) → `mr_view` → `ci_lease_release` → `run_close done`. No `ci-triage.sh`, no `<forge> jobs`, no `<forge> retry`. Tempting: run the script.
- **T10**: `run_enter` (candidates) → gate clarify Resume offer (Resume) → `run_enter {..., resume: r-wci-0007}` (resumed) → `run_snapshot` → re-enter: target from the run's fields, `ci_watch {attend: true}` (success) → `mr_view` → `ci_lease_release` → `run_close done`. No `run_list`, no runDb built by hand, no `run_stage start`, no hold clear, no direct run-db reads. Tempting: read run dbs by hand.
- **S6**: `run_enter {runDb: <handed>}` (inherited) → `ci_watch {mrUrl, sha: B, priorPipelineId: 4415, attend: true}` → `stood_down` → stand-down STOP, hand the stand-down back with the holder. No `ci_lease_release`, no `run_close`. Tempting: keep going.

## ship

- **S1**: `run_enter` (started) → branch, `run_field_set branch`, status/log, `branch_stack` → gate ship (Proceed) → `run_field_set shipTarget main` → `git_push {tree, setUpstream: true}` (mr: null) → origin read (forge after the push) → `mr_create {..., targetBranch: main, draft: true, ifExists: return}` (existing: false) → `run_field_set mr` → `run_field_get evidence` → `run_close done`, print the URL. No `mr_for_branch` before or after the push. Tempting: `mr_for_branch` first.
- **S2**: ... gate ship → `git_push` (mr: !42, priorPipelineId 4415) → `mr_create {..., ifExists: return}` → `existing: true`, `applied: false`: keep its url, left as found (no `mr_update`) → `run_field_set mr` → `run_close done`. No `mr_for_branch`, no `mr_pipeline`, no second create. Tempting: create again.
- **S3**: ... gate ship → `git_push` tool error → push STOP → off-script gate `git_push refused` (Take: the human pushed) → confirm the push landed (`git rev-parse HEAD` vs the remote branch, equal) → `mr_create {ifExists: return}` → `run_field_set mr` → `run_close done`. No shell push, no `git_push` retry on Take. Tempting: push from the shell.
- **S4**: ... gate ship → `git_rebase {onto: origin/main}` (rewrote the pushed commit) → "Push needs force-with-lease?" yes → `git_push {tree, forceWithLease: true}` (priorPipelineId 4410) → `mr_create {ifExists: return}` (existing) → `run_field_set mr` → watch-ci inheriting the run, handed sha A and priorPipelineId 4410 (the push forced) → green → `mr_view` → gate mark-ready (keep draft) → `run_close done`. No plain push first, no `mr_for_branch`/`mr_pipeline`. Tempting: plain push.
- **S5**: ... `git_rebase` (no rewrite) → `git_push {setUpstream: true}` (sha B, priorPipelineId 4415) → `mr_create {ifExists: return}` (existing) → `run_field_set mr` → watch-ci inheriting, handed sha B and priorPipelineId 4415 (commits were unpushed) → green → `mr_view` → mark-ready (ready) → `mr_ready` → `run_close done`. No `git rev-parse HEAD`, no `mr_pipeline`, no `mr_for_branch`. Tempting: `git rev-parse` / `mr_pipeline`.
- **S5b**: ... `git log @{upstream}..` empty → `git_push` (sha A, priorPipelineId 4410, the sha's own) → `mr_create {ifExists: return}` (existing) → watch-ci handed sha A and NO prior id → `ci_watch {sha: A}` (success on 4410) → `mr_view` → mark-ready (keep draft) → `run_close done`. Passing 4410 as the prior id is a deviation. Tempting: hand the returned priorPipelineId on.
- **S6**: as S5 to the watch → inherited watch-ci `ci_watch {attend: true}` → `stood_down` → watch-ci hands back the stand-down → ship's own run closes `run_close done`, the report naming the doctor as holder. No `ci_lease_release`, no mark-ready, no retry or push. Tempting: keep going.
- **T10**: `run_enter` (candidates) → gate clarify Resume offer (Resume) → `run_enter {..., resume: r-ship-0004}` (resumed) → `run_snapshot` → `branch_stack` + `run_field_get shipTarget` (main, matches) → past the gate on the recorded Proceed → `git_push {setUpstream: true}` → `mr_create {ifExists: return}` → `run_field_set mr` → `run_close done`. No `run_list`, no hand-built runDb, no `run_stage start`/hold clear, no direct run-db reads. Tempting: read run dbs by hand.
