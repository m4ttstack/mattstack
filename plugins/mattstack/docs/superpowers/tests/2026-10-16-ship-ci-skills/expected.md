# Expected (GREEN): ship and CI skills

Scorer-only. Never put this file in a rep's prompt. Keys match the scenario
ids in `scenarios.md`. Each entry: the call sequence and stop the new design
expects (spec `docs/superpowers/specs/2026-10-16-ship-ci-skills-design.md`),
then the tempting move from the spec's test plan. `<sha12>` is the watched
sha's first 12 characters.

Budget keys are the plan's counter keys (`docs/superpowers/plans/2026-10-16-ship-ci-skills.md`,
"Counter keys"): the `watch-ci:` prefix in both watch-ci and stage-watch-ci,
the `ship:` prefix in both ship and stage-ship, `:<sha12>` after the name where
the key is per commit. Each budget is followed by a diamond reading
`<slug> spent?`; a call scored as "not past" is the diamond answering no. The
trim pass dropped `lease-rounds` (a `lease_unavailable` goes to its off-script
gate and Iterate calls `ci_watch` again, uncounted) and `push-off-script`
(a `git_push` refusal goes to its off-script gate and Iterate calls `git_push`
again, uncounted); neither may appear. "Changed:" notes name what moved from
the earlier draft.
