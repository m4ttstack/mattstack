`rt glitter` opens a GitHub Desktop style git client in the terminal you run it from: changes with per-line checkboxes, diff, commit, history, stash, and the repo, worktree, and branch foldouts. It needs an interactive terminal. It opens the repo you are in, or the last one you opened, and never registers it with rt.

The [Glitter guide](/guides/glitter) walks through the board, the staging model, and every key.
