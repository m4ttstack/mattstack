# rt setup update

`rt › setup › update`

Re-apply setup after an app update

## Usage

```bash
rt setup update [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `--force` | boolean | `false` | Run even when this version was already applied |
| [`--json`](/guides/common-flags) | boolean | `false` | Machine-readable result |
