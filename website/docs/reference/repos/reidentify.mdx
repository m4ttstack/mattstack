# rt repos reidentify

`rt › repos › reidentify`

Update rt after a repo is renamed

## Usage

```bash
rt repos reidentify <old-identity> <new-identity> [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `<old-identity>` | text |  | The identity every store is keyed on today; raw host/path or serialized remote: form |
| `<new-identity>` | text |  | The identity the repo's remote derives now |
| [`--dry-run`](/guides/common-flags) | boolean | `false` | Print per-store counts without writing |
| [`--json`](/guides/common-flags) | boolean | `false` | Machine-readable result |
