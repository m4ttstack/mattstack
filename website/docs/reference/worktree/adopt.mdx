# rt worktree adopt

`rt › worktree › adopt`

Bring a repo's existing worktrees under rt

## Usage

```bash
rt worktree adopt [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| [`--repo`](/guides/common-flags) | text |  | Registered repo name (required) |
| `--claim` | boolean | `false` | Take ownership: adopt foreign worktrees as auto-disposing ephemerals (default: leave them unmanaged, untouched) |
| [`--json`](/guides/common-flags) | boolean | `false` | Print the raw result as JSON |
