# rt logins

`rt › logins`

Save dev-server logins that browser runs can use on a login page

## Usage

```bash
rt logins
```

## Subcommands

| Command | Description |
| --- | --- |
| [`list`](list) | Show your saved dev logins, never the passwords |
| [`add`](add) | Save or replace the dev login for a site |
| [`open-add`](open-add) | Open mattstack to save a dev login for a site |
| [`remove`](remove) | Delete a saved dev login |
