# rt skills discard

`rt › skills › discard`

Throw away this pack's changes that are not synced yet

## Usage

```bash
rt skills discard [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `--pack` | text |  | Pack whose changes to throw away; required, since this never guesses |
| `--expect` | text |  | Throw them away only if they are still the ones rt skills changes showed with this signature |
| [`--json`](/guides/common-flags) | boolean | `false` | Machine-readable result |
