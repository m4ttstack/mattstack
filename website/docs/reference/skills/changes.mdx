# rt skills changes

`rt › skills › changes`

List this pack's changes that are not synced yet

## Usage

```bash
rt skills changes [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `--pack` | text |  | Pack name (--team still accepted); omit to pick from the discovered packs, or run from inside a pack tree to act on that tree |
| [`--json`](/guides/common-flags) | boolean | `false` | Machine-readable result |
