# rt skills expand

`rt › skills › expand`

Paste mattstack attachments into hand-written skills: each &#123;&#123;include:&lt;name&gt;&#125;&#125; line in &lt;src&gt;/&lt;skill&gt;/SKILL.md is replaced and the result written to &lt;out&gt;/&lt;skill&gt;/

## Usage

```bash
rt skills expand [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `--src` | text |  | Directory holding one skill dir per skill |
| `--out` | text |  | Directory expand owns: every skill dir in it is regenerated or removed |
| `--mattstack-dir` | text |  | Resolve plugins from &lt;dir&gt;/plugins/&lt;name&gt; instead of the installed set |
| `--check` | boolean | `false` | Compare the output to a fresh expansion and exit 1 on drift; write nothing |
| `--strict` | boolean | `false` | Fail on mcp-lint hits in the output (shell forms a mattstack tool covers) |
| [`--dry-run`](/guides/common-flags) | boolean | `false` | Print what would be written without touching disk |
| [`--json`](/guides/common-flags) | boolean | `false` | Machine-readable result |
