# rt skills check

`rt › skills › check`

Report compiled skills that no longer match their sources

## Usage

```bash
rt skills check [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `--pack` | text |  | Pack name (--team still accepted); omit to pick from the discovered packs, or run from inside a pack tree to check that tree |
| `--verb` | text |  | Check only this verb (repeatable); omit for every compiled verb |
| `--manifest` | text |  | Manifest path; omit to read ~/.mattstack/repos/&lt;repo&gt;/packs/&lt;pack&gt;/skills.jsonc |
| [`--repo`](/guides/common-flags) | text |  | Which repo's bindings file to read when this pack binds several; omit for the first repo the team declares |
| `--pack-dir` | text |  | Check this pack directory's sources (a worktree, say) instead of resolving --pack through the registry |
| `--strict` | boolean | `false` | Fail the exit code on mcp lint hits (the plugin-mattstack CI job uses this; rt skills sync applies it to a pack whose plugin.json sets strictLint) |
| [`--json`](/guides/common-flags) | boolean | `false` | Machine-readable result |
