# rt ci watch

`rt › ci › watch`

Watch the MR's pipeline for a pushed sha

## Usage

```bash
rt ci watch <mr> [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `<mr>` | text |  | MR URL |
| `--sha` | text |  | The pushed commit |
| `--max-wait` | text |  | Seconds, up to 1800 |
| `--interval` | text |  | Seconds, 10 to 120 |
| `--prior-pipeline` | text |  | Head pipeline id before the push |
| [`--json`](/guides/common-flags) | boolean | `false` | Emit the result as JSON |
