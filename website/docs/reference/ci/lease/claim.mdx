# rt ci lease claim

`rt › ci › lease › claim`

Claim the MR's CI lease for this session

## Usage

```bash
rt ci lease claim <mr> [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `<mr>` | text |  | MR or PR URL |
| `--holder` | text |  | watch-ci (default) or doctor |
| `--branch` | text |  | Source branch, recorded on the lease |
| [`--json`](/guides/common-flags) | boolean | `false` | Emit the result as JSON |
