# rt team pull

`rt › team › pull`

Pull the local team clone up to date with its remote, through the daemon's snapshot supervisor

## Usage

```bash
rt team pull [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `--team` | text |  | Which org clone; leave out, since a Mac holds one |
