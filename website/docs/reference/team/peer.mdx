# rt team peer

`rt › team › peer`

Connect this Mac's own board to the switchboard, so it can trade asks with your teammates' boards

## Usage

```bash
rt team peer [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `--team` | text |  | Which cloned team; omit when only one is cloned |
| `--rotate` | boolean | `false` | Issue a new board token even if the switchboard already knows your board; a board still using the old one stops working |
| [`--json`](/guides/common-flags) | boolean | `false` | Machine-readable result |
