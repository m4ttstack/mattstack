# rt team create

`rt › team › create`

Start an org for your team, with its first team inside

## Usage

```bash
rt team create <name> [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `<name>` | text |  | The org's display name; its folder name is made from it |
| `--first-team` | text |  | The first team's name; the org's own name when left out |
| `--remote` | text |  | An existing empty repo's URL |
| `--create-repo` | text |  | Owner (user or org) to create &lt;owner&gt;/mattstack-team-&lt;slug&gt; under via gh, instead of pasting --remote |
| `--others` | boolean | `false` | Mark the team as having members beyond you |
| [`--json`](/guides/common-flags) | boolean | `false` | Machine-readable result |
