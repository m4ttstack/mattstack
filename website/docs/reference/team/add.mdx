# rt team add

`rt › team › add`

Add a team to your org, with its owners

## Usage

```bash
rt team add <team> [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `<team>` | text |  | The new team's name: lowercase letters, digits and dashes |
| `--owner` | text |  | Forge usernames who may change this team's settings and pack, comma separated |
| [`--json`](/guides/common-flags) | boolean | `false` | Machine-readable result |
