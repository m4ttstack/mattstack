# rt settings set

`rt › settings › set`

Write a setting for you, your org, your team or this Mac

## Usage

```bash
rt settings set <key> <value> [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `<key>` | text |  | Namespaced settings key (must be migrated:true) |
| `<value>` | text |  | JSON(C) value |
| `--scope` | select |  | Which store to write into |
| [`--repo`](/guides/common-flags) | text |  | Registered repo (name, path, or identity); required for repo-scoped keys |
| `--team` | text |  | A team's name, for --scope team; your own team when left out |
