# rt git push

`rt › git › push`

Push this branch, fixing its upstream if needed

## Usage

```bash
rt git push [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `--remote` | text |  | Remote to push to |
| [`--dry-run`](/guides/common-flags) | boolean | `false` | Show the git command without running it |
| `--no-verify` | boolean | `false` | Skip pre-push hooks |
