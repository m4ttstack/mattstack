# rt git rebase

`rt › git › rebase`

Rebase onto main and auto-resolve easy conflicts

## Usage

```bash
rt git rebase [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| [`--dry-run`](/guides/common-flags) | boolean | `false` | Show what would happen without doing it |
| [`--json`](/guides/common-flags) | boolean | `false` | On conflict, emit a JSON conflict bundle and exit 3 instead of prompting |
| [`--agent`](/guides/common-flags) | boolean | `false` | On conflict, skip the prompt and hand off straight to a Claude agent in herdr (requires a TTY) |
| [`--no-agent`](/guides/common-flags) | boolean | `false` | On conflict, never offer agent escalation; abort instead |
