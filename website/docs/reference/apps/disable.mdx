# rt apps disable

`rt › apps › disable`

Turn an app off (deck stops it and the window hides it)

## Usage

```bash
rt apps disable <name> [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `<name>` | text |  | App name from rt apps list |
| [`--json`](/guides/common-flags) | boolean | `false` | Machine-readable result |
