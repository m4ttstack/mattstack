# rt apps

`rt › apps`

The mattstack apps deck serves on this Mac (board, console, chat, boxscore)

## Usage

```bash
rt apps
```

## Subcommands

| Command | Description |
| --- | --- |
| [`list`](list) | List the apps and whether each is on |
| [`enable`](enable) | Turn an app on (deck serves it and the window shows it) |
| [`disable`](disable) | Turn an app off (deck stops it and the window hides it) |
