# rt herd follow-up

`rt › herd › follow-up`

Reopen a done job for a follow-up round: active again until its next report

## Usage

```bash
rt herd follow-up <job> [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `<job>` | text |  | Job name |
| `--herd` | text |  | Herd id (default: HERD_ID) |
| [`--json`](/guides/common-flags) | boolean | `false` | Emit the follow-up record as JSON |
