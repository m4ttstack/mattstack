# rt home

`rt › home`

The git-backed ~/.mattstack/user personal repo

## Usage

```bash
rt home
```

## Subcommands

| Command | Description |
| --- | --- |
| [`init`](/rt/reference/home/init) | Provision this machine: print, then run, the plan (which clones or git-inits the user repo as one of its steps) |
| [`key`](/rt/reference/home/key) | The mattstack age key (keychain-custodied) |
| [`restore`](/rt/reference/home/restore) | Bring your settings over from another Mac |
| [`remote`](/rt/reference/home/remote) | Where the home repo is backed up |
| [`snapshot`](/rt/reference/home/snapshot) | Run the snapshot daemon now (or show its status with --status) |
| [`claim`](/rt/reference/home/claim) | Claim a zone so the daemon leaves it for you to commit by hand |
| [`release`](/rt/reference/home/release) | Release a claimed zone so the daemon resumes auto-committing it |
