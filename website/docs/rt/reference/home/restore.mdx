# rt home restore

`rt › home › restore`

Bring your settings over from another Mac

## Usage

```bash
rt home restore <repo> [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `<repo>` | text |  | Your settings repo: owner/repo on GitHub, host/owner/repo, or its clone address |
| `--stdin` | boolean | `false` | Read the recovery key from stdin instead of a no-echo prompt |
| `--profile` | text |  | A name for this Mac's new profile, when its default name is taken |
| [`--json`](/rt/guides/common-flags) | boolean | `false` | Machine-readable result |
