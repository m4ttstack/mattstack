# rt pr enqueue

`rt › pr › enqueue`

Add a PR to the merge queue

## Usage

```bash
rt pr enqueue <pr> [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `<pr>` | text |  | PR number |
| `--head` | text |  | Refuse unless the branch is at this full sha |
| [`--json`](/rt/guides/common-flags) | boolean | `false` | Emit the result as JSON |
