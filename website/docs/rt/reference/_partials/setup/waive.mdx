Skips a setup step on this Mac so the setup wizard can finish without it. In the app, the same steps sit in the checklist's **You can skip** card, each with a **Skip** button. Three steps can be skipped:

- `skills.overrides`: Skill overrides
- `tool.chrome-signin`: Chrome sign-in, shown only when a team pack needs it
- `tool.mission-control`: Mission Control shortcut

Any other id is refused. The Fast Browser extension and your writing style also hold Finish, but neither can be skipped.

```bash
rt setup waive tool.mission-control     # skip the Mission Control shortcut
rt setup unwaive tool.mission-control   # bring it back later
```

`rt setup unwaive` also clears a Fast Browser extension skip saved by an older version of mattstack.
