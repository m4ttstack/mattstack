### Starting on a base pack

`--extends <base>` names an org base pack. Init writes `"extends": "<base>"` into the new pack. When the base's text asks the team for values, init seeds a place for each. A key gets an empty string in `pack/params.jsonc`, and a section gets an empty `pack/sections/<name>.md`. Init then stops (`params-missing`) with the list and the base file that asks for each. Fill them in and run the same command again. Init resumes, leaves the files as they are, and carries on through compile, check, install and publish. See [Team values in shared fills](/skills/packs#team-values-in-shared-fills).
