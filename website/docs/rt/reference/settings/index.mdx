# rt settings

`rt › settings`

Configure tokens, team, and repo data

## Usage

```bash
rt settings
```

## Subcommands

| Command | Description |
| --- | --- |
| [`get`](/rt/reference/settings/get) | Read a resolved setting (value + provenance) through the settings resolver |
| [`set`](/rt/reference/settings/set) | Write a setting for you, your org, your team or this Mac |
| [`unset`](/rt/reference/settings/unset) | Remove a setting from one layer |
| [`list`](/rt/reference/settings/list) | List every registered setting resolved through the settings resolver |
| [`explain`](/rt/reference/settings/explain) | Show the full scope chain for one setting, weakest first |
| [`check`](/rt/reference/settings/check) | Check every stored settings value against its schema and list unregistered keys |
| [`migrate`](/rt/reference/settings/migrate) | Carry stored settings to each key's current store name; a dry run unless --write or --prune |
| [`test-push`](/rt/reference/settings/test-push) | Send a test push notification via rt tray |
| [`extension`](/rt/reference/settings/extension) | Install RT Context extension in editors |
| [`source-path`](/rt/reference/settings/source-path) | Show or set the rt source checkout the dev app runs |
| [`schema`](/rt/reference/settings/schema) | The settings schema lock: regenerate it from the registry, or diff the registry against a committed lock |
