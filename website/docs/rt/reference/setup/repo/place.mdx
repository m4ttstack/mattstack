# rt setup repo place

`rt › setup › repo › place`

Record an existing checkout of a repo, or the folder a new clone of it goes in

## Usage

```bash
rt setup repo place [<repo>] [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `<repo>` | text |  | The repo as host/path; omit to pipe &#123;"identity", "mode", "path"&#125; on stdin |
| `--checkout` | text |  | An existing checkout of the repo |
| `--clone-to` | text |  | The folder a new clone becomes |
| [`--json`](/rt/guides/common-flags) | boolean | `false` | Machine-readable result |
