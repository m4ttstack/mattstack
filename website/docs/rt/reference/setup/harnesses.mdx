# rt setup harnesses

`rt › setup › harnesses`

Choose which agent apps rt turns on, and which one it starts by default

## Usage

```bash
rt setup harnesses <apps> [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `<apps>` | text |  | The agent apps to turn on, in your order (claude, codex) |
| `--default` | text |  | The app rt agent starts by default; one of those you turn on |
| `--none` | boolean | `false` | Turn every agent app off |
| [`--json`](/rt/guides/common-flags) | boolean | `false` | Machine-readable result |
