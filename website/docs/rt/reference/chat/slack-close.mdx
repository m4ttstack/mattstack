# rt chat slack-close

`rt › chat › slack-close`

Close a Slack support chat

## Usage

```bash
rt chat slack-close [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `--pane` | text |  | The pane whose chat to close; this session's own chat when left out |
| `--farewell-file` | text |  | A file holding the goodbye to send first |
| [`--json`](/rt/guides/common-flags) | boolean | `false` | Emit the result as JSON |
