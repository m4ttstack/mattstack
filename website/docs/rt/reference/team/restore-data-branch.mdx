# rt team restore-data-branch

`rt › team › restore-data-branch`

Push your copy of the org's data branch back to a forge that lost it

## Usage

```bash
rt team restore-data-branch [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `--yes` | boolean | `false` | Push without asking; leave it out to see what would be pushed |
| `--team` | text |  | Which org clone; your only one when left out |
| [`--json`](/rt/guides/common-flags) | boolean | `false` | Machine-readable result |
