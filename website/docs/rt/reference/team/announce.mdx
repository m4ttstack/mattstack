# rt team announce

`rt › team › announce`

As an org admin, send a notification to everyone in your org

## Usage

```bash
rt team announce <title> [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `<title>` | text |  | A short headline, up to 80 characters |
| `--message` | text |  | The details, up to 500 characters |
| `--team` | text |  | Which org clone; your only one when left out |
| [`--json`](/rt/guides/common-flags) | boolean | `false` | Machine-readable result |
