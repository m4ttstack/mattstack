# rt team invite

`rt › team › invite`

Invite someone to your org and put them on a team

## Usage

```bash
rt team invite [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `--handle` | text |  | The invitee's forge username |
| `--team` | text |  | Which org clone; leave out, since a Mac holds one |
| `--teams` | text |  | The teams to put them on, comma separated; your own team when left out |
| `--require-peering` | boolean | `false` | Refuse to mint an invite that cannot carry the invitee's board token |
| [`--json`](/rt/guides/common-flags) | boolean | `false` | Machine-readable result |
