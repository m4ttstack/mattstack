# rt team members drop

`rt › team › members › drop`

Take someone off one of your teams

## Usage

```bash
rt team members drop <username> [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `<username>` | text |  | The member's forge username |
| `--from` | text |  | The team to take them off |
| `--team` | text |  | Which org clone; your only one when left out |
| [`--json`](/rt/guides/common-flags) | boolean | `false` | Machine-readable result |
