# rt team members

`rt › team › members`

Members: collect keys, change teams, remove someone

## Usage

```bash
rt team members
```

## Subcommands

| Command | Description |
| --- | --- |
| [`set`](/rt/reference/team/members/set) | Change which teams someone is on |
| [`add`](/rt/reference/team/members/add) | Put someone in your org on one of your teams |
| [`drop`](/rt/reference/team/members/drop) | Take someone off one of your teams |
| [`sync`](/rt/reference/team/members/sync) | Collect every outstanding invite's reply key and add it as a sops recipient |
| [`remove`](/rt/reference/team/members/remove) | Revoke forge access, drop the roster entry, and re-encrypt without the member's key |
