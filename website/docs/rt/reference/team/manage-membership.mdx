# rt team manage-membership

`rt › team › manage-membership`

Let mattstack add and remove teammates' read access on a team repo it created

## Usage

```bash
rt team manage-membership [<state>] [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `<state>` | select |  | Omit to show the current state |
| `--team` | text |  | Which org clone; leave out, since a Mac holds one |
| [`--json`](/rt/guides/common-flags) | boolean | `false` | Machine-readable result |
