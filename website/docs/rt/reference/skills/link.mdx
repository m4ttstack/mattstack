# rt skills link

`rt › skills › link`

Symlink a skills/*/SKILL.md tree into your agent's skills folder by frontmatter name (create, repoint, prune; conflicts reported, never touched)

## Usage

```bash
rt skills link [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `--from` | text |  | Link this directory instead of the current repo's skills/ (no checkout needed) |
| [`--dry-run`](/rt/guides/common-flags) | boolean | `false` | Print what would change without touching disk |
| `--harness` | text |  | Do this for one agent (claude or codex); omit for your default agent |
| [`--json`](/rt/guides/common-flags) | boolean | `false` | Machine-readable result |
