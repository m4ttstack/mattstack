# rt skills direct-only

`rt › skills › direct-only`

Choose which pack skills Claude runs only when you type them

## Usage

```bash
rt skills direct-only
```

## Subcommands

| Command | Description |
| --- | --- |
| [`list`](list) | See which of a pack's skills run only when you type them |
| [`set`](set) | Make pack skills run only when you type them, or let Claude pick them again |
| [`reapply`](reapply) | Put your choices back on the installed skills |
