# rt skills direct-only

`rt › skills › direct-only`

Choose which pack skills Claude runs only when you type them

## Usage

```bash
rt skills direct-only <mode> [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `<mode>` | text |  | list \| set &lt;name&gt;... --on\|--off \| reapply |
| `--pack` | text |  | list and set: the pack's name; omit to pick from the discovered packs |
| `--on` | boolean | `false` | set only: run the named skills only when you type them |
| `--off` | boolean | `false` | set only: let Claude pick the named skills again |
| [`--json`](/rt/guides/common-flags) | boolean | `false` | Machine-readable result |
