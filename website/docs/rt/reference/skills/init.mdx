# rt skills init

`rt › skills › init`

Scaffold your team's pack with a generic work pipeline, declare the repo, compile, check, and install it

## Usage

```bash
rt skills init [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| [`--repo`](/rt/guides/common-flags) | text |  | Repo to declare; defaults to the current directory |
| `--team` | text |  | The team folder that gets the pack; your own team when left out |
| `--zone` | text |  | The org, which must be the one this Mac uses |
| `--extends` | text |  | A shared base pack your org keeps; rt adds an empty place for each value it asks your team for |
| [`--json`](/rt/guides/common-flags) | boolean | `false` | Machine-readable result |
