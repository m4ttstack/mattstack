# rt skills blocks

`rt › skills › blocks`

Show one skill as its tree of blocks, with each layer's text

## Usage

```bash
rt skills blocks [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `--pack` | text |  | Pack name (--team still accepted); omit to pick from the discovered packs, or run from inside a pack tree to act on that tree |
| `--skill` | text |  | Skill or stage name |
| `--manifest` | text |  | Manifest path; omit to read ~/.mattstack/repos/&lt;repo&gt;/packs/&lt;pack&gt;/skills.jsonc |
| [`--repo`](/rt/guides/common-flags) | text |  | Which repo's bindings file to read when this pack binds several; omit for the first repo the team declares |
| [`--json`](/rt/guides/common-flags) | boolean | `false` | Machine-readable result |
