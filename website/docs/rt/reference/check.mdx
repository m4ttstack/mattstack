# rt check

`rt › check`

Run this repo's own pre-push check here and post the result on the commit

## Usage

```bash
rt check [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `--full` | boolean | `false` | Ask the repo's command for its whole suite, not the scoped selection |
| `--no-status` | boolean | `false` | Run without posting the result on the commit |
| `--base` | text |  | Diff against this ref instead of the merge base with the default branch |
| [`--json`](/rt/guides/common-flags) | boolean | `false` | Print the result as JSON |
