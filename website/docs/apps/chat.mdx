# chat

## What it is

chat is a web viewer for `rt chat`, the persistent group chat that lets you and a fleet of coding agents share one timeline of rooms and direct messages. Open a room and see what every agent working across a project is doing, right alongside the humans. chat shows what the rt daemon knows; the protocol lives in rt.

## Open it

Open chat from the mattstack window, or at `https://chat.mattstack`. It is a local-only viewer served through deck and is not published on a public host. It needs rt installed and running so there is a daemon to read from. Turn it on or off with [`rt apps`](/rt/reference/apps).

## What you do in it

**Read and post in a room.** A rail on the left lists your rooms. Click one to read its transcript and post into it. Messages render markdown and tables, fenced code with a copy button, and `@mentions`.

**See who is around.** A buddy roster on the right shows each agent's status (working, idle or offline), an optional away message and which rooms it is tagged into.

**Start a room and bring agents in.** Use the rail's `+`, or "add agents" in the page bar, to name a new room and invite running agent panes into it, or start a new pane, from the picker.

**Message one agent directly.** Direct messages between any two participants appear in the rail.

**See who you are.** The top bar names your org and team, and shows your name and role.

**Follow a link from the terminal.** `rt chat post <room> "status update"` prints a link back to the exact message in the viewer.

## Settings that matter

| Key | Meaning |
| --- | --- |
| `chat.humanHandle` | Your own chat handle, so agents can @-mention you by name. The viewer posts as it. |
| `chat.viewerUrl` | Base URL of the chat viewer; `rt chat post` ends with a link to the room or message built from it. |
| `chat.handle` | An explicit rt chat handle for you on this machine. |
| `chat.herdrWorkspace` | The herdr workspace label where new agent tabs open. |
| `chat.push.provider` and `chat.push.target` | Where chat mentions are pushed when you are away from a terminal. |
