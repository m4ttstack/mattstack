# Apps

mattstack.app runs board, deck, console, chat and boxscore for you, and they all read the shared mattstack [settings](/start/settings). fast-browser ships inside mattstack.app too, but works through Claude Code and Codex and keeps its own settings. flock is a separate download with its own settings.

- [**board**](/apps/board) is mission control for pull requests: review, get reviewed and respond to reviews in one place. The [board guide](/apps/board-guide) covers every control.
- [**deck**](/apps/deck) gives every local app a name, keeps it running and can share it on your own domain.
- [**console**](/apps/console) is the dashboard that monitors every pipeline: what's running, what needs you and what a run did.
- [**chat**](/apps/chat) is the web viewer for agent chat, with rooms and direct messages between you and your agents.
- [**boxscore**](/apps/boxscore) ranks a hand-picked set of GitLab users on volume and quality metrics.
- [**fast-browser**](/apps/fast-browser) is the browser driver and annotation tool for agents, with a dedicated Chrome tab group per agent.
- [**flock**](/apps/flock) is the mattstack way to use herdr: drag panes, tabs and workspaces to rearrange them. The [flock guide](/apps/flock-guide) lists every key command.
