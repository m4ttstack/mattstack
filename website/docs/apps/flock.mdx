# flock

## What it is

flock is a native macOS window onto your [herdr](https://github.com/herdrdev/herdr) session. It is the mattstack way to use herdr: drag and drop anything you see to move or rearrange it. It also supports keyboard navigation and improves how you interact with herdr notifications. The project is in continual development.

## Open it

Download the `.dmg` from flock's [latest release](https://github.com/m4ttstack/flock/releases/latest), open it and drag Flock onto Applications. It needs macOS 15 or later on Apple silicon and herdr 0.9 or later on your `PATH`. Start herdr the way you normally do, then open Flock. It attaches to your default herdr session and shows it straight away, and offers a Start herdr button if herdr is not running. Flock checks for updates by itself, or use Flock > Check for Updates.

## What you do in it

**Rearrange.** Drag panes, tabs and workspaces to move them, inside a workspace or across workspaces in [Arrange](#arrange).

**See what needs you.** Every pane carries a [status](#statuses), and [Overview](#overview) sorts every pane by what it needs from you.

**Work from the keyboard.** Every command has a key, listed under [Key commands](#key-commands), and the command palette (<kbd>⌘</kbd><kbd>K</kbd>) finds any of them by name.

**Use rt from a pane.** If you run agents with rt, each pane gets an rt button that opens `rt nav`, `rt glitter`, `rt run` and `rt runner` in a modal. Herds get their own sidebar section with progress read from rt, and rt chat is a click away. None of it is needed to use flock with plain herdr.

## The three views

The tabs at the top of the window switch between three views of the same session: Workspaces, Overview and Arrange. The View menu, the palette and <kbd>⌘</kbd><kbd>1</kbd> to <kbd>⌘</kbd><kbd>3</kbd> switch them too.

### Workspaces

The live window, where you work. The sidebar on the left lists your workspaces in sections: PINNED, WORKSPACES, and, when you use rt, BOARD for the board app's workspaces and HERDS for running herds. Notifications stack at the foot of the sidebar. The tab strip runs along the top, and the selected tab's panes fill the rest.

Drag sidebar rows, tabs and panes to move them, right-click any of them for its menu, and double-click a name to rename it. Clicking empty space in the sidebar or the tab strip opens a new workspace or tab.

### Overview

Every pane as a card, sorted into three lanes by what it needs from you:

- **NEEDS YOU** holds blocked panes, then done ones. When it is empty it says "Nothing needs you".
- **WORKING** holds working panes, then BACKGROUND: Claude Code panes still running something behind their prompt (see [Background work](#background-work)).
- **AT REST** holds everything else, by when it last changed: Last hour, Earlier today, Yesterday, This week, Older and Unknown.

Cards are grouped under their workspace's symbol and name. Each card shows:

- the pane's status mark and title.
- how long it has been in that state, for example "blocked 12m".
- its branch.
- a timeline of its status over the last hour.

**Card detail** in Settings chooses what the branch line shows: the branch, the repo and branch, or nothing. Branch leaves out the repo when it matches the workspace's name.

Board review workspaces and herds' agent workspaces show in the lanes too. Turn either off in Settings with **Include Board reviews** or **Include herds**.

Click a card, or select it and press <kbd>↩</kbd>, to open it. The pane opens on its own and live, so you can type into it. The header has a "‹ Overview" button back, and a NEXT chip naming the next pane waiting on you, or a "Queue clear" badge when nothing is. While Overview is not the view you are on, its tab carries a red count of blocked panes.

When you leave Overview with a pane open and come back, you see the lanes. **Coming back shows** in Settings can reopen the pane you had open instead.

### Arrange

One island per workspace, holding a live thumbnail of each tab's split layout. Drag panes, tabs and whole workspaces between islands. Drop:

- on the middle of a pane to swap with it, or move there.
- on a pane's edge to split it.
- on a tab to move into that tab.
- on empty space to make a new tab.

Hover a tab or workspace during a drag and it springs open.

Click a pane to select it and double-click (or press <kbd>↩</kbd>) to open it in Workspaces. Zoom into one workspace from its island's Zoom button, by double-clicking its header, or with <kbd>Space</kbd>. Right-click a pane for Rename Pane, Copy Output and Close Pane. Typing never reaches a terminal from Arrange.

## Statuses

flock draws one status mark per pane from what herdr reports about the agent running in it, and draws it the same way everywhere: the sidebar, tabs, cards, switchers and notifications. A tab, workspace or herd shows its loudest pane, in the order blocked, done, working, idle.

The colors below are from Tokyo Night (Tokyo Night Day on a light page), flock's default theme; other themes use their own shades of the same colors.

| Mark | Status | What it means |
| --- | --- | --- |
| <FlockStatus status="working" /> | working | The agent is working. |
| <FlockStatus status="blocked" /> | blocked | The agent stopped and is waiting for you. Its notification stays until you answer it, and its card stays in NEEDS YOU until it is unblocked. |
| <FlockStatus status="done" /> | done | The agent finished. It clears to idle once you look at the pane. |
| <FlockStatus status="idle" /> | idle | An agent is in the pane, idle. |
| <FlockStatus status="background" /> | background work | Claude Code is back at its prompt but still running something. See [Background work](#background-work). |
| <FlockStatus status="unknown" /> | no agent | A plain shell, or anything else herdr detects no agent in. Its pane label reads "idle", dimmed. |

A pane's label carries the status word in the same color: working, blocked, done or idle.

### Background work

herdr calls a Claude Code pane idle or done as soon as Claude Code is back at its prompt, even while background shells, monitors or subagents are still running. flock reads the footer under Claude Code's prompt every 10 seconds. When the footer counts any of those, the pane shows the background work mark, a mauve ring, in place of idle or done.

The pane label shows the reason in place of the status word, for example "1 shell", "2 monitors" or "1 subagent". In Overview the card moves to WORKING under BACKGROUND, with the reason and its age, such as "1 shell · 3m". When the work ends, the pane goes back to idle or done.

### Plain shells

flock has no statuses of its own for a plain shell: a shell running a long build looks the same as one sitting at its prompt, the small muted dot. Closing a plain shell never asks first, since no agent runs in it.

### The launcher

When a pane's shell sits at an empty prompt, a launcher bar shows over it: in a new pane, after <kbd>⌃</kbd><kbd>L</kbd> or `clear`, after rt cd, and in a pane flock sees for the first time after it restarts. The bar offers rt cd, claude and codex on <kbd>⌘</kbd><kbd>1</kbd> to <kbd>⌘</kbd><kbd>3</kbd>, and hides on your first keystroke or when the pane prints anything. rt cd runs `rt cd --repo`, so it picks from every repo.

### Other marks

- A tab marked complete (right-click a tab > Mark Complete) shows a mauve checkmark, dims and moves to the right end of the strip.
- A zoomed pane shows a mauve "Zoomed" badge in its label.
- An empty pinned workspace shows no mark, with its symbol and name dimmed.
- rt runs listed in a pane's rt menu show a green dot while running, grey once finished and red once exited.

## Closing a pane or tab

Closing a pane or tab that runs an agent asks first: Claude Code, Codex or any other agent herdr detects, idle or busy. The prompt reads "Close this pane?" or "Close this tab?", says how many agent sessions the close ends, and offers **Close Pane** or **Close Tab** and **Cancel**. When the close also takes its tab or workspace, the prompt names that instead.

Tick **Don't warn me next time** to stop the prompt for that kind of close, tabs or panes, whichever button you press. Turn it back on in Settings under **Closing**. A busy pane, or a workspace's last tab, asks either way.

Close Workspace (<kbd>⌥</kbd><kbd>⇧</kbd><kbd>⌘</kbd><kbd>W</kbd>) does not check for agents.

## Pinned workspaces

A pinned workspace keeps its place at the top of the sidebar, under PINNED, and comes back when you click it after its last tab closes.

### Pin a workspace

Right-click the workspace in the sidebar and choose **Pin**. Once you have one pin, the PINNED section exists and you can also drag a row from WORKSPACES into it; the first pin has to come from the menu, because PINNED is not drawn until a pin exists.

A pin keeps the workspace's name and one folder. When you pin, a popover titled "*name* opens in" asks which folder:

- **where the shell is now**: the folder the shell is in at that moment. It reads "where the shell was last seen" when flock cannot ask the shell.
- **where it started**: the folder the shell started in.
- **Other…**: any folder you pick.

Close the popover without choosing to keep the folder it highlights. Pin names are unique: pinning a second workspace with the same name is refused.

### Change the pinned workspace's folder

1. Right-click the pinned workspace in the sidebar.
2. Choose **Change Folder…**.
3. In the folder picker, which opens on the current folder and asks where the workspace opens, pick the folder you want and click **Choose**.

You can do this any time, on a live pinned workspace or an empty one. The folder only matters when flock opens the workspace again: it does not move the panes that are already open.

### What a pin does

- A pinned workspace's menu has no Close. Closing its last tab closes the herdr workspace and leaves an empty pin, dimmed in the sidebar. flock asks first only when that tab runs an agent (see [Closing a pane or tab](#closing-a-pane-or-tab)). If you were on the workspace, its empty pin stays on screen.
- Choosing an empty pin in the sidebar or the <kbd>⌃</kbd><kbd>Tab</kbd> switcher shows it: its symbol, name and folder, "Pinned · no tabs open", and a launcher bar of shell, rt cd, claude and codex. Nothing opens yet.
- To open it, press <kbd>↩</kbd> for a shell, choose a launcher item (or press <kbd>⌘</kbd><kbd>1</kbd> to <kbd>⌘</kbd><kbd>3</kbd>), or press <kbd>⌘</kbd><kbd>T</kbd>. flock opens a new workspace in the pin's folder, under the pin's name. Tabs, splits and commands are not restored.
- If the pin's folder no longer exists, the workspace opens in your home folder and tells you to pick another with Change Folder….
- flock does not reopen pins when it starts. An empty pin whose name matches a workspace herdr already has links to it.
- Renaming a pinned workspace in herdr renames the pin.
- Drag pins to reorder them. PINNED comes first in the sidebar, and in the workspace keys and switcher too.
- Pins are kept on this Mac only.

### Unpin

Right-click the pinned workspace and choose **Unpin**, or drag it down into WORKSPACES. It stays open as an ordinary workspace. An empty pin cannot be dragged out; its menu offers **Remove** instead.

### Title bar workspaces

**Move to Top Bar** in a workspace's menu pins it and moves it to an icon in the title bar, beside the view tabs. The menu of a pinned or empty pinned workspace offers it too. The icon's color is the workspace's status.

- Click the icon to open the workspace in an overlay. Close the overlay with its close button, a click on the backdrop, or the icon again. <kbd>Esc</kbd> goes to the pane's program.
- The overlay's size control offers Small, Medium and Large, remembered for each workspace.
- A top-bar workspace holds one tab. A workspace with more tabs cannot move there until you close the extras.
- A top-bar workspace leaves the sidebar, Overview, Arrange, the switcher and notifications.
- Drag icons to reorder them, or drag a pin between the title bar and PINNED.
- While the overlay is open, New Tab, New Workspace, Close Tab, Close Workspace and the pane direction keys are off.
- Right-click the icon for Move to Sidebar, Rename, Change Icon… and Unpin.

**Title Bar Workspaces** in Settings chooses Icon only or Icon and name.

## Workspace symbols

Every workspace wears an SF Symbol beside its name. It shows in the sidebar, Overview's group headers, Arrange's island headers and an opened card's header. flock gives each new workspace the least-used symbol on its own, so no two look alike until you have many.

To choose one, click the symbol, or right-click the workspace and choose **Change Symbol…**. The picker lists 216 symbols in eight groups (Engineering, Work, Tools, Nature, Things, Travel and sport, Shapes, Animals), with the current one highlighted. Type in **Search symbols** to filter by name or group; <kbd>↩</kbd> picks the first match. **Automatic** hands the choice back to flock.

No symbol is a check, exclamation mark, clock, bell, cross or plain circle, since those shapes belong to statuses, and color in the sidebar only ever means status. A workspace keeps its symbol when you rename it, pin it or unpin it. The board app's workspaces wear the board logo and herds wear the ram mark; neither can be changed.

## Key commands

Keys are written the way the macOS menus write them: <kbd>⌃</kbd> Control, <kbd>⌥</kbd> Option, <kbd>⇧</kbd> Shift, <kbd>⌘</kbd> Command. Most of them also sit in the menu bar and in the command palette (<kbd>⌘</kbd><kbd>K</kbd>), which shows each command's key beside it.

Pane commands use <kbd>⌘</kbd> because it is the one modifier a pane's program never receives, so they never collide with what runs inside a pane.

## Settings that matter

flock has no keys in the mattstack settings registry. Its own Settings (<kbd>⌘</kbd><kbd>,</kbd>) has four tabs: General, Views, Tools and herdr.

| Tab | Section | Setting | Choices |
| --- | --- | --- | --- |
| General | Starting Folder | New Workspace, New Tab, New Pane | Current Pane's Folder, Repo's Main Checkout (home outside a git repo), Home Folder or Custom Folder…. New workspaces and panes start in the current pane's folder and new tabs in the repo's main checkout. |
| General | Notifications | Show in sidebar | Until seen (the default), For 5 seconds or Never. A question stays until you answer it. |
| General | Titles | One title for a one-pane tab | On by default: a tab holding one pane shows one title everywhere. |
| General | Title Bar Workspaces | Show | Icon only (the default) or Icon and name. |
| General | Closing | Warn before closing a tab running an agent, Warn before closing a pane running an agent | Both on by default. |
| Views | Overview | Card detail | Branch (the default), Repo and branch, or Hidden. |
| Views | Overview | Coming back shows | The lanes (the default) or The pane you had open. |
| Views | Overview | Include Board reviews, Include herds | Both on by default. Off, those workspaces leave the lanes and the tab's count. |
| Views | Rearrange Mode | After a move | Exit (the default) or Stay. |
| Tools | rt Modal Text Size | rt cd, rt nav, rt glitter, rt run, rt runner | Compact, Regular (the default) or Large. |
| Tools | Command Line | Shell command | Installs a `flock` command on your `PATH`, to control flock from a terminal or over ssh. |
| herdr | herdr | Version | The connected herdr's version, or Not connected. |
| herdr | herdr | Mouse support | Installs a build of your herdr version that passes clicks and scrolling through to panes, or restores the original. |

The View menu holds the rest: Theme (Tokyo Night by default, among 17), Terminal Text, Option as Alt (Left Option by default) and Scroll Speed.
