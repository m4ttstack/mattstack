# Terminology

One approved term per concept on docs.mattstack.dev. Use the approved column
in pages, PR descriptions and UI copy; never rotate in the words under Avoid.
Add a row when a page introduces a concept.

| Concept | Approved | Avoid |
| --- | --- | --- |
| A GitLab merge request | MR ("merge request" on first use) | PR, pull request |
| The menu a right-click on a board row opens | row menu | context menu, right-click menu |
| A Claude Code session board or flock starts in a herdr pane | agent | bot, worker, assistant |
| The member a board belongs to (`board.defaultMember`) | seat | user, identity, owner |
| A request from your board to a teammate's agent | ask | peer request, job |
| The badge in each flock pane for what its agent is doing | status | state, badge, indicator |
| Claude Code back at its prompt with shells, monitors or subagents still running | background work | mauve ring, busy |
| A workspace kept at the top of flock's sidebar | pinned workspace, pin | favorite, bookmark |
| flock's three window modes | view (Workspaces, Overview, Arrange) | mode, screen, page |
| A mattstack app deck runs from source, reloading as you edit | live, go live | dev mode, hot mode, watch mode |
